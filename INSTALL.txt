PDF Suite Pro — Quick Install
=============================

Full details: INSTALLATION.txt

WINDOWS (Installer)
-------------------
1. Download PDFSuitePro_Installer.exe (in this repository)
2. Run the installer and follow the wizard
3. Launch from Start Menu or desktop shortcut
4. Uninstall via Windows "Apps & Features"

WINDOWS (Portable — no install)
-------------------------------
Double-click: PDF Suite Pro.exe

Desktop shortcut: right-click PDF Suite Pro.exe → Create shortcut
Or run in PowerShell:

  $ws = New-Object -ComObject WScript.Shell
  $sc = $ws.CreateShortcut("$env:USERPROFILE\Desktop\PDF Suite Pro.lnk")
  $sc.TargetPath = "C:\full\path\to\PDF Suite Pro.exe"
  $sc.Save()

SUPPORTED WINDOWS VERSIONS
--------------------------
Windows 7, 8, 8.1, 10, 11 — 32-bit and 64-bit.
(The app is built as a 32-bit executable so it runs on all of them.)

FROM SOURCE
-----------
pip install -r requirements.txt
python pdf_tool.py

BUILD EXE
---------
pip install -r requirements.txt
pip install pyinstaller
pyinstaller --onefile --noconsole --name "PDF Suite Pro" pdf_tool.py
pyinstaller --onefile --console  --name "PDFSuiteCLI" pdf_cli.py

Output: dist/PDF Suite Pro.exe  and  dist/PDFSuiteCLI.exe

For a Windows 7–compatible build use Python 3.8 (32-bit):
  pip install PyMuPDF==1.23.26 Pillow==10.4.0 pyinstaller==5.13.2 tkinterdnd2 qrcode
  pyinstaller --onefile --windowed --name "PDF Suite Pro" pdf_tool.py

BUILD INSTALLER
---------------
makensis pdfsuite_pro.nsi        (NSIS — recommended)
Output: PDFSuitePro_Installer.exe

Note: pdfsuite_pro.iss (Inno Setup) is an alternative installer script.
