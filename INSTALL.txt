PDF Merger & Splitter - Quick Install
======================================

For full installation details, see INSTALLATION.txt

WINDOWS (Pre-built)
-------------------
Run: dist/PDFMerger.exe
  (Double-click, no installation needed)

WINDOWS / MAC / LINUX (from source)
------------------------------------
1. pip install -r requirements.txt
2. python pdf_tool.py

BUILD WINDOWS EXE
------------------
pip install pyinstaller
pyinstaller --onefile --noconsole --name "PDFMerger" --hidden-import fitz pdf_tool.py

ANDROID (build APK)
-------------------
cd android/
buildozer android debug

DEPENDENCIES
-------------
PyMuPDF     - required (PDF engine)
Pillow      - optional (page thumbnails)

For issues, visit: https://github.com/learnerarchitecture-debug/PDFMERGER
