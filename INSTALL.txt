PDF Merger & Splitter - Quick Install
======================================

Full details: INSTALLATION.txt

WINDOWS (Pre-built)
-------------------
Double-click: dist/PDFMerger.exe
Desktop shortcut: right-click -> Create shortcut

FROM SOURCE
-----------
pip install -r requirements.txt
python pdf_tool.py

BUILD EXE
---------
pip install pyinstaller
pyinstaller --onefile --noconsole --name "PDFMerger" --hidden-import fitz pdf_tool.py

ANDROID
-------
cd android/ && buildozer android debug
