PageDeck — Quick Install
========================

Full details: INSTALLATION.txt

WINDOWS (Installer)
-------------------
1. Download PageDeck_Installer.exe (in this repository)
2. Run the installer and follow the wizard
3. Launch from Start Menu or desktop shortcut
4. Uninstall via Windows "Apps & Features"

Upgrading from "PDF Suite Pro" v4.x? Just run the installer — the old
version is removed automatically and your settings carry over.

WINDOWS (Portable — no install)
-------------------------------
Double-click: PageDeck.exe

Desktop shortcut: right-click PageDeck.exe → Create shortcut
Or run in PowerShell:

  $ws = New-Object -ComObject WScript.Shell
  $sc = $ws.CreateShortcut("$env:USERPROFILE\Desktop\PageDeck.lnk")
  $sc.TargetPath = "C:\full\path\to\PageDeck.exe"
  $sc.Save()

SUPPORTED WINDOWS VERSIONS
--------------------------
Windows 7, 8, 8.1, 10, 11 — 32-bit and 64-bit.
(The app is built as a 32-bit executable so it runs on all of them.)

FROM SOURCE
-----------
pip install -r requirements.txt
python pdf_tool.py

BUILD EXE
---------
pip install -r requirements.txt
pip install pyinstaller
pyinstaller --noconfirm --clean "PageDeck.spec"
pyinstaller --onefile --console --noconfirm --name "PageDeckCLI" --icon app_icon.ico pdf_cli.py

Output: dist/PageDeck.exe  and  dist/PageDeckCLI.exe

For a Windows 7–compatible build use Python 3.8 (32-bit):
  pip install PyMuPDF==1.23.26 Pillow==10.4.0 pyinstaller==5.13.2 tkinterdnd2 qrcode

BUILD INSTALLER
---------------
makensis pagedeck.nsi        (NSIS — recommended)
Output: PageDeck_Installer.exe

Note: pagedeck.iss (Inno Setup) is an alternative installer script.
