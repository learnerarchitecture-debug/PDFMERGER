PDF Suite Pro — Quick Install
=============================

Full details: INSTALLATION.txt

WINDOWS (Installer)
--------------------
1. Download PDFSuitePro_Installer.exe from GitHub Releases
2. Run the installer and follow the wizard
3. Launch from Start Menu or desktop shortcut

FROM SOURCE
-----------
pip install -r requirements.txt
python pdf_tool.py

BUILD EXE
---------
pip install -r requirements.txt
pip install pyinstaller
pyinstaller --onefile --noconsole --name "PDF Suite Pro" pdf_tool.py

Output: dist/PDF Suite Pro.exe

ANDROID
-------
cd android/
buildozer android debug
