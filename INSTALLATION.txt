PDF Suite Pro — Installation Guide
================================

App:     PDF Suite Pro
Creator: AYUSH GUPTA
Version: v2.3
Repo:    https://github.com/learnerarchitecture-debug/PDFMERGER


Option 1: Pre-built Executable (Recommended)
---------------------------------------------

1. Download PDF Suite Pro Installer from the GitHub Releases page.
2. Run the installer (PDFSuitePro_Installer.exe).
3. Follow the setup wizard - the application will be installed to:
   C:\Program Files\PDF Suite Pro
4. A desktop shortcut will be created automatically.
5. Launch PDF Suite Pro from the Start Menu or desktop shortcut.

Option 2: Run from Source (Python)
-----------------------------------

Requirements: Python 3.8+

   pip install -r requirements.txt
   python pdf_tool.py


Option 3: Build Your Own Executable
--------------------------------------

Requirements:
   pip install -r requirements.txt
   pip install pyinstaller
   pyinstaller --onefile --noconsole --name "PDF Suite Pro" pdf_tool.py

Output: dist/PDF Suite Pro.exe


Option 4: Manual Portable Use
-----------------------------

1. Download PDF Suite Pro.exe from the GitHub repository.
2. No installation required - runs from any folder.
3. Create a desktop shortcut:
   - Right-click PDF Suite Pro.exe → Create shortcut
   - Or pin to Taskbar

Dependencies
-------------
- PyMuPDF (required) — PDF engine
- Pillow — Image compression
- PyInstaller — Windows exe build

Troubleshooting

"Windows protected your PC"
  Click "More info" → "Run anyway" (standard for unsigned exe).

App doesn't start
  Run from cmd to see errors: .\PDF Suite Pro.exe

"No module named 'fitz'"
  pip install PyMuPDF

Rate & Review
  App menu → Rate & Review (1–5 stars). Feedback saved locally.

System Requirements
-----------------
- Windows 7, 8, 8.1, 10, or 11 (32-bit or 64-bit)
- 2 GB RAM minimum (4 GB recommended)
- 100 MB free disk space
- .NET Framework 4.7.2 (included with Windows 10/11, optional for Win 7)
