PDF Merger & Splitter - Installation Guide
============================================

Option 1: Using the Pre-built Executable (Recommended)
-------------------------------------------------------

1. Double-click `dist/PDFMerger.exe` to run.
   - No installation required.
   - Portable — runs from any folder.

2. Create a desktop shortcut:
   - Right-click `dist/PDFMerger.exe` -> Show more options -> Create shortcut
   - Or run this in PowerShell:
     ```
     $ws = New-Object -ComObject WScript.Shell
     $sc = $ws.CreateShortcut("$env:USERPROFILE\Desktop\PDFMerger.lnk")
     $sc.TargetPath = "C:\full\path\to\dist\PDFMerger.exe"
     $sc.Save()
     ```

Option 2: Running from Source (Python)
---------------------------------------

Requirements: Python 3.8+

   pip install -r requirements.txt
   python pdf_tool.py

Option 3: Building Your Own Executable
---------------------------------------

   pip install -r requirements.txt
   pip install pyinstaller
   pyinstaller --onefile --noconsole --name "PDFMerger" --hidden-import fitz pdf_tool.py

   Output: dist/PDFMerger.exe

Option 4: Android App (Build APK)
----------------------------------

Requirements: Linux or WSL with Python 3.8+ and Buildozer.

   cd android/
   pip install buildozer
   buildozer android debug

   Output: android/bin/PDFMerger-*-debug.apk

Dependencies
-------------

- PyMuPDF  (required) - PDF engine
- PyInstaller (Windows exe build)
- Kivy, Plyer (Android build)

Troubleshooting
---------------

- "Windows protected your PC":
  Click "More info" -> "Run anyway" (standard for unsigned exe).

- Antivirus false positive:
  Verify at VirusTotal or build from source yourself.

- App doesn't start:
  Run from cmd to see errors: .\PDFMerger.exe

- "No module named 'fitz'":
  pip install PyMuPDF
