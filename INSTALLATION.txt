PageDeck — Installation Guide
=============================

App:     PageDeck (formerly "PDF Suite Pro")
Creator: AYUSH GUPTA
Version: v5.1.2
Repo:    https://github.com/learnerarchitecture-debug/PDFMERGER


Upgrading from PDF Suite Pro (v4.x)
-----------------------------------
Just run the PageDeck installer — it removes the old "PDF Suite Pro"
installation automatically (folder, shortcuts and Apps & Features entry).

Your settings, saved signature, recent files and automation recipes are
carried over to PageDeck on first launch.

Already using a portable copy? Simply replace the old exe with PageDeck.exe.


Updating to a new version
-------------------------
PageDeck updates itself:

  - At startup it quietly checks GitHub for a newer release.
    The repository is public — no token or configuration needed.
  - If one exists, the app downloads the installer automatically
    (release notes + progress bar are shown) and asks one question:
    "Restart & Install". PageDeck closes while the setup updates it.
  - Manual check: menu  Help → Check for Updates,
    or the "Check for updates" button on the Home tab.
  - Preferences: menu  Help → Update settings…
      * Check for updates at startup          (on by default)
      * Download new versions automatically   (on by default)

Note: the update system uses GitHub Releases of this repository.
Only install releases published there by the project author.


What's in the box
-----------------
   PageDeck.exe              The application (Home / Organize / Edit PDF /
                             Convert & Secure / Images / Automation —
                             6 tabs, 100+ tools)
   PageDeckCLI.exe           Command-line companion for scripts and
                             scheduled tasks (optional)

The setup wizard installs both. The portable exe runs on its own.


Option 1: Setup Wizard (Recommended)
-------------------------------------

1. Download PageDeck_Installer.exe from this repository.
2. Run it (Administrator permission is requested automatically).
3. Follow the wizard — the application installs to:
     C:\Program Files\PageDeck
4. Desktop and Start Menu shortcuts are created automatically.
5. Launch PageDeck from the desktop or Start Menu.
6. To remove: Windows Settings → Apps → PageDeck → Uninstall
   (an uninstaller is also placed in the install folder).

The installer checks your Windows version and supports
Windows 7, 8, 8.1, 10, and 11 (32-bit and 64-bit).


Option 2: Portable — Run Without Installing
-------------------------------------------

1. Download PageDeck.exe from this repository.
2. Double-click it — no installation required, runs from any folder.
3. Optional: right-click → Create shortcut, or pin to Taskbar.

Tip: also download PageDeckCLI.exe and put it next to the app exe if you
want the command-line tools (recipes, watch folders, scheduling).


Option 3: Script Installer (from source)
----------------------------------------

1. Build the exes first (see Option 5) so that dist\PageDeck.exe
   (and optionally dist\PageDeckCLI.exe) exists.
2. Right-click install.bat → "Run as administrator".
3. It copies the app to C:\Program Files\PageDeck, creates shortcuts,
   and adds an uninstaller to Apps & Features.


Option 4: Run from Source (Python)
----------------------------------

Requirements: Python 3.8+

   pip install -r requirements.txt
   python pdf_tool.py


Option 5: Build Your Own Executables
------------------------------------

   pip install -r requirements.txt
   pip install pyinstaller
   pyinstaller --noconfirm --clean "PageDeck.spec"
   pyinstaller --onefile --console --noconfirm --name "PageDeckCLI" --icon app_icon.ico pdf_cli.py

   Output: dist\PageDeck.exe  and  dist\PageDeckCLI.exe

   Then build the installer (optional, requires NSIS):
     makensis pagedeck.nsi
   Output: PageDeck_Installer.exe

   For a Windows 7–compatible 32-bit build use Python 3.8:
     pip install PyMuPDF==1.23.26 Pillow==10.4.0 pyinstaller==5.13.2
     pip install tkinterdnd2 qrcode


Option 6: Android App (Build APK)
----------------------------------

Requirements: Linux or WSL with Python 3.8+ and Buildozer.

   cd android/
   pip install buildozer
   buildozer android debug

   Output: android/bin/pdfmerger-*-debug.apk


Optional external tools
-----------------------
PageDeck detects these automatically and offers the download page if a
feature needs one:

   Tesseract OCR    — "OCR scan → searchable PDF"
                      Get it: github.com/UB-Mannheim/tesseract
   LibreOffice      — "Word / Excel / PPT → PDF"
                      Get it: libreoffice.org

Everything else works out of the box.


Command line (PageDeckCLI)
--------------------------

   PageDeckCLI.exe ops                     list recipe operations
   PageDeckCLI.exe merge a.pdf b.pdf -o merged.pdf
   PageDeckCLI.exe compress big.pdf --target 5
   PageDeckCLI.exe ocr scan.pdf --lang eng
   PageDeckCLI.exe split-keyword binder.pdf --keyword "SECTION"
   PageDeckCLI.exe img-scan photo.jpg
   PageDeckCLI.exe img-social *.jpg --preset "Instagram post"
   PageDeckCLI.exe recipe -r recipe.json -d "C:\Scans" -o "C:\Out"
   PageDeckCLI.exe watch  -d "C:\Scans" -r recipe.json -o "C:\Out"
   PageDeckCLI.exe schedule --name NightRun -r recipe.json -d "C:\Scans" -o "C:\Out" --time 23:00

Full command reference: see README.md.

- customtkinter            — Modern UI toolkit

Troubleshooting
---------------

"Windows protected your PC"
  Click "More info" → "Run anyway" (standard for unsigned exe).

Antivirus false positive
  Verify at VirusTotal or build from source yourself.

App doesn't start
  Run from cmd to see errors: "PageDeck.exe"
  (or use PageDeckCLI.exe to verify the engine works)

Drag & drop does nothing
  Some shells block DnD; use the Add files buttons instead —
  everything is also in File menu.

"OCR needs Tesseract" / "Needs LibreOffice"
  Install the free tool (links above) and try again. PageDeck finds it
  automatically in the standard install locations.

"No module named 'fitz'"
  pip install PyMuPDF

Scheduled task doesn't run
  Open Task Scheduler → Task Scheduler Library → "PageDeck" and check
  the task's last-run result. Make sure the recipe file path still exists.

Rate & Review
  Home tab → Rate & Review (1–5 stars). Feedback saved locally.
